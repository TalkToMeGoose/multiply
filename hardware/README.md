# Hardware sources

Reserved for KiCad schematic/PCB sources and a hand-wiring fallback diagram. PCB design with AI assistance became the preferred route to investigate on 2026-10-17; the separate physical prototype remains skipped. No electrical design files exist yet. Follow the [PCB learning plan](../docs/pcb-learning-plan.md).

The preliminary topology and pin budget are in [architecture](../docs/architecture.md). Before creating a footprint or drilling a carrier, verify the actual switch contact pairs and terminal dimensions. Identify GPIO names separately from physical Pico header pin numbers in every wiring table.
